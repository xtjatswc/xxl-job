# XXL-JOB 信创改造说明文档（适配金仓数据库 KingbaseES）

## 一、改造概述

本文档说明 xxl-job 项目从 MySQL 迁移到金仓数据库 KingbaseES 的改造内容。

### 改造范围
- xxl-job-admin 模块的数据访问层
- MyBatis Mapper XML 文件
- 数据库初始化脚本
- Maven 依赖配置

---

## 二、KingbaseES 兼容性差异

### 2.1 SQL 语法差异

| 功能 | MySQL 语法 | KingbaseES 语法 | 影响范围 |
|------|-----------|----------------|---------|
| 分页 | `LIMIT offset, pagesize` | `LIMIT pagesize OFFSET offset` | 所有分页查询 |
| 字符串拼接 | `CONCAT('%', var, '%')` | `'%' \|\| var \|\| '%'` | Like 查询 |
| 空值处理 | `IFNULL(expr, default)` | `COALESCE(expr, default)` | 统计查询 |
| 日期计算 | `DATE_ADD(now, INTERVAL n SECOND)` | `now - INTERVAL 'n' SECOND` | 注册表超时查询 |
| 插入更新 | `ON DUPLICATE KEY UPDATE` | `ON CONFLICT (...) DO UPDATE SET` | 主键冲突处理 |
| 自增序列 | `AUTO_INCREMENT` | `SERIAL` / `BIGSERIAL` | 建表语句 |
| 存储引擎 | `ENGINE=InnoDB` | 无需指定（默认） | 建表语句 |
| 字符集 | `DEFAULT CHARSET=utf8mb4` | `ENCODING='UTF8'` | 建表语句 |
| 索引方法 | `USING BTREE` | 默认 B-tree，无需指定 | 建表语句 |
| 大文本 | `MEDIUMTEXT` | `TEXT` | 建表语句 |

### 2.2 数据类型差异

| MySQL 类型 | KingbaseES 类型 | 说明 |
|-----------|----------------|-----|
| `TINYINT` | `SMALLINT` | KingbaseES 无 TINYINT |
| `MEDIUMTEXT` | `TEXT` | 长度相同，KingbaseES 统一用 TEXT |
| `DATETIME` | `TIMESTAMP` | 功能等价 |
| `BIGINT AUTO_INCREMENT` | `BIGSERIAL` | 自动创建序列 |
| `INT AUTO_INCREMENT` | `SERIAL` | 自动创建序列 |

## 四、详细改动说明

### 4.1 LIMIT 语法改造

**问题**：MySQL 支持 `LIMIT offset, pagesize`，KingbaseES 仅支持标准 SQL `LIMIT pagesize OFFSET offset`

**示例**：
```xml
<!-- 原 MySQL 语法 -->
LIMIT #{offset}, #{pagesize}

<!-- Kingbase 兼容语法 -->
LIMIT #{pagesize} OFFSET #{offset}
```

涉及文件：
- XxlJobInfoMapper.xml
- XxlJobLogMapper.xml
- XxlJobGroupMapper.xml
- XxlJobUserMapper.xml

### 4.2 字符串拼接改造

**问题**：MySQL 支持嵌套 CONCAT，KingbaseES 使用标准 `\|\|` 运算符

**示例**：
```xml
<!-- 原 MySQL 语法 -->
AND t.name like CONCAT(CONCAT('%', #{name}), '%')

<!-- Kingbase 兼容语法 -->
AND t.name like '%' || #{name} || '%'
```

涉及文件：
- XxlJobInfoMapper.xml
- XxlJobGroupMapper.xml
- XxlJobUserMapper.xml

### 4.3 空值处理改造

**问题**：MySQL 的 IFNULL 函数在 KingbaseES 中需改用 COALESCE

**示例**：
```xml
<!-- 原 MySQL 语法 -->
IFNULL(COUNT(handle_code),0) triggerDayCount

<!-- Kingbase 兼容语法 -->
COALESCE(COUNT(handle_code),0) triggerDayCount
```

涉及文件：
- XxlJobLogMapper.xml

### 4.4 日期计算改造

**问题**：MySQL 的 DATE_ADD 函数在 KingbaseES 中使用标准日期运算

**示例**：
```xml
<!-- 原 MySQL 语法 -->
WHERE t.update_time < DATE_ADD(#{nowTime}, INTERVAL -#{timeout} SECOND)

<!-- Kingbase 兼容语法 -->
WHERE t.update_time < #{nowTime} - INTERVAL '#{timeout}' SECOND
```

涉及文件：
- XxlJobRegistryMapper.xml

### 4.5 插入更新改造

**问题**：MySQL 的 `ON DUPLICATE KEY UPDATE` 在 KingbaseES 中使用 `ON CONFLICT DO UPDATE`

**示例**：
```xml
<!-- 原 MySQL 语法 -->
INSERT INTO xxl_job_registry(...) VALUES(...)
ON DUPLICATE KEY UPDATE update_time = #{updateTime}

<!-- Kingbase 兼容语法 -->
INSERT INTO xxl_job_registry(...) VALUES(...)
ON CONFLICT (registry_group, registry_key, registry_value)
DO UPDATE SET update_time = #{updateTime}
```

涉及文件：
- XxlJobRegistryMapper.xml
- XxlJobLogReportMapper.xml

### 4.6 建表脚本改造

**主要改动**：
```sql
-- 原 MySQL 语法
CREATE TABLE xxl_job_group (
    id INT NOT NULL AUTO_INCREMENT,
    ...
) ENGINE = InnoDB DEFAULT CHARSET = utf8mb4;

-- Kingbase 兼容语法
CREATE TABLE xxl_job_group (
    id SERIAL,
    ...
);
```

涉及文件：
- `doc/db/kingbase/tables_xxl_job.sql`

## 六、部署步骤

### 6.1 数据库初始化

```bash
# 连接 KingbaseES
ksql -U SYSTEM -d xxl_job

# 执行建表脚本
\i /path/to/doc/db/kingbase/tables_xxl_job.sql
```

### 6.2 编译打包

```bash
cd xxl-job
mvn clean package -DskipTests
```

### 6.3 启动应用

```bash
java -jar xxl-job-admin/target/xxl-job-admin-3.5.1-SNAPSHOT.jar
```

## 七、注意事项

1. **驱动版本**：Kingbase8 驱动版本建议使用 8.6.0 或更高版本
2. **端口号**：KingbaseES 默认端口为 54321（不同于 PostgreSQL 的 5432）
3. **用户权限**：确保 SYSTEM 用户有足够的数据库操作权限
4. **字符集**：数据库创建时指定 `ENCODING='UTF8'`
5. **Mapper 路径**：如需切换到 Kingbase 版本，修改 `mybatis.mapper-locations` 配置

## 九、常见问题

### Q1: 启动时报 "关系不存在" 错误
**A**: 检查是否执行了 Kingbase 版本的建表脚本

### Q2: 分页查询返回结果为空
**A**: 检查 LIMIT 语法是否正确转换为 `LIMIT pagesize OFFSET offset`

### Q3: 字符串模糊查询不生效
**A**: 检查 LIKE 条件是否使用 `\|\|` 拼接而非 CONCAT

### Q4: 主键自增失败
**A**: 检查是否使用 SERIAL 类型而非 AUTO_INCREMENT

## 十、调试日志中的关键问题及修复

### Q1: BindingException - Invalid bound statement (not found): XxlJobLockMapper.scheduleLock
**原因**：`mapper/kingbase/XxlJobLockMapper.xml` 方法名与 Java 接口不匹配（写了 getLock/addLock/delLock，实际接口是 scheduleLock）。
**修复**：补全 scheduleLock 方法，使用标准 SQL `FOR UPDATE` 语法。

### Q2: TypeException - Error setting non null for parameter #2, column index out of range
**原因**：`INTERVAL '#{timeout}' SECOND` 中单引号将参数当成字面量，Kingbase JDBC 驱动参数绑定错位。
**修复**：改为 `${timeout} * INTERVAL '1' SECOND`，避免参数绑定冲突。

### Q3: KSQLException - operator does not exist: timestamp without time zone < dsinterval
**原因**：`90 * INTERVAL '1' SECOND` 在 Kingbase 中被解析为 `dsinterval`（持续时间），无法与 `timestamp` 比较。
**修复**：改为 `INTERVAL '${timeout} SECOND'`，直接将数值内联进 interval 字符串，只有一个参数占位符 `#{nowTime}`，避免类型冲突。
